# Praktikum 1 Grafika Komputer - GDI+ Kompleks

Aplikasi C# Windows Forms yang menampilkan objek kompleks bermakna (Pemandangan Rumah) menggunakan modul GDI+.


## Elemen GDI+ yang Digunakan
1. Langit - FillRectangle
2. Rumput - FillRectangle
3. Matahari - FillEllipse
4. Sinar Matahari - DrawLine
5. Dinding Rumah - FillRectangle & DrawRectangle
6. Atap Rumah - FillPolygon
7. Pintu & Jendela - FillRectangle & FillEllipse
8. Pohon - FillRectangle & FillEllipse
9. Teks Label - DrawString
